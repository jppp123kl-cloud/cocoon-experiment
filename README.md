# 信息茧房与破茧助手：中期进展

我们想了解：持续接触相近观点和错误信息，会不会让判断出错、过度自信，或忽略重要证据？补充可靠信息和引导反思，能否改善这些问题？


## 先看这两个入口

下载仓库后，用浏览器打开根目录的 **[index.html](index.html)**：我们制作的一些动画。

**[assistant.html](assistant.html)** 是当前可体验的破茧助手程序。
提供连接模型的分析模式（API，即模型服务接口），以及无需连接的内置示例模式。

助手基于已有原型调整，沿用功能与本次修改见 [来源说明](docs/来源说明.md)。

## 已经完成的工作

- 助手能按步骤整理信息、标注来源、寻找遗漏、形成报告，并结合用户原话提出反思问题。
- 实验程序能分配四种信息环境的材料，保存阅读经历，复制干预前状态，并进行四次测量与评分。
- 已围绕气候、能源、天气三个现实议题，以及一个虚构交通情境，开展真实模型的小规模试验。
- 已保存材料、模型回答、失败尝试和评分结果，方便回查。另有使用程序生成回答的流程演练，它只用于检查程序，不作为研究结果。

## 目前观察到了什么

**现实议题在开始时就被答对了。** 三个议题中，模型在阅读材料前的核心事实正确率已经是 100%。这限制了我们通过正确率观察信息环境和干预的作用。

**虚构情境中，提供证据改善了回答。** 直接提供核查证据、提供同样证据并加入助手反思的两组，核心事实正确率都从 50% 升到 100%，后续四轮阅读后保持。
