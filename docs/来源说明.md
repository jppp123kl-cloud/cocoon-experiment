# 项目来源与修改范围

这个仓库是在已有项目上继续整理的。这里把来源写清楚，便于区分沿用的功能和后续修改。

## 实验仓库

本仓库 fork 自 [jppp123kl-cloud/cocoon-experiment](https://github.com/jppp123kl-cloud/cocoon-experiment)。实验程序、历史运行记录和原版四幕展示均已存在于所取得的版本中。本次界面与中期文档整理不代表重新完成了这些实验。

## 破茧助手原型

助手来自此前下载的“破茧认知助手 / CocoonBreaker”。仓库保存的来源记录指向 [原发布帖](https://forum.trae.cn/t/topic/113322)，发布账号为 `u3951005207114857`。这些信息来自已有的 `vendor/cocoon-breaker-original/provenance.json`，本次没有重新核验论坛页面。

沿用的部分包括：模式选择、话题输入、分步分析、报告、认知镜、自检、内置示例和模型调用逻辑。当前 `assistant.html` 保留原有功能脚本，外观调整在 `web/assistant-polish.css`，键盘操作补充在 `web/assistant-polish.js`。

本次修改包括：助手视觉调整、两页独立入口、中期展示辅助内容精简、面向老师的说明，以及页面检查与重建脚本。没有把原型改称为从零开发的作品。

## 保留与清理

原始网页、下载压缩包和来源记录用于核对历史实验版本，继续保留。删除了不参与运行的两份展开文档：原参赛介绍，以及独立的四阶段提示词说明。原压缩包仍包含这两份文件，来源记录中的文件清单记载的是当时取得的完整附件。

本次本地检查没有发现独立的 LICENSE 文件。已有来源记录也将授权状态记为未确认；这份说明只是来源记录，不是授权书，也不授予新的使用或再发布许可。
